# ChatWave

A realtime messaging web app built with React, Vite and Supabase.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Build
Run `npm run build`; deploy the generated `dist` folder to a static hosting provider.

The browser app uses only the Supabase publishable key. Never put a service-role key in frontend code.

## Current milestone
- Supabase email authentication
- User profiles
- Direct one-to-one text conversations
- Realtime message updates

Voice/video calls, group chat, media uploads, push notifications, end-to-end encryption and Android packaging are future milestones and are not enabled yet.
